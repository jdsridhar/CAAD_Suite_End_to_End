# Structure source fixture G-STRUCT-1

The fixture contains the unmodified RCSB PDBx/mmCIF file for entry 5NIU, downloaded from
https://files.rcsb.org/download/5niu.cif on 2026-09-24. RCSB/wwPDB archive data files are
provided under the CC0 1.0 Universal Public Domain Dedication; see
https://www.rcsb.org/pages/usage-policy.

It is used to validate parsing of an experimental method/resolution, entity polymer sequence,
four protein chains, two copies of reference ligand 8YZ, non-polymer filtering, and explicit
chain/ligand choice requests. This is parser/selection coverage, not a docking benchmark or
biological validation. SHA256SUMS pins the downloaded source bytes.
