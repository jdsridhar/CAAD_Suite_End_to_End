## Zero-occupancy side-chain finding

The source atom-site table contains 14 side-chain atom records at exactly zero occupancy: four atoms in `A:62 LYS`, six in `A:150 ARG`, and four in `A:223 LYS`. These records have coordinates, so the current PDBFixer worker's `findMissingAtoms()` does not classify them as missing. A first, unmodified worker run consequently reported `missing_heavy_atom_count=0`. That output is not acceptable evidence that these side chains are observed or prepared.

For a controlled trial only, a separate mmCIF derivative was written in scratch after removing precisely those 14 zero-occupancy atom records. Derivative SHA-256: `a619314a56dc2b9ad12e6f6b3c848e427bbddf3f3a9b34168c63f5ff63e4f31d`. The original source was not modified. Running the existing PDBFixer worker on this derivative with chains `A,B`, pH 7.4, seed 44101, and internal-gap modeling enabled reported `missing_heavy_atom_count=14`, produced 4,401 atoms across 286 residues, and retained the inter-chain disulfide at 2.547 Å. Prepared mmCIF SHA-256: `0892f3514a51c6d7a326e63dc85316d3509ea5f6f1c6a67d477a77a36d28cc63`; PDB derivative SHA-256: `e3a65d4b6d372d92a94fdee809537eb4f592e17495551a3224a2e269fdd3c851`.

The worker's reported absence of nonbonded heavy-atom contacts below 1.5 Å applies only to the prepared protein and is not a ligand clash check, side-chain rotamer validation, or force-field readiness result. This manual derivative is evidence for a candidate-specific trial, not yet a platform policy. The generic preparation path should identify zero-occupancy records and require an explicit, provenance-recorded resolution instead of silently treating them as observed atoms. Other partial occupancies still require review.

## Ligand graph/coordinate mapping

The 38 non-hydrogen `_chem_comp_atom` entries for IK8, ordered by `pdbx_ordinal`, have the same element sequence as the 38 heavy atoms in the deposited CCD ideal SDF. The CCD `_chem_comp_bond` graph and the SDF heavy-atom graph each contain 42 edges and have identical atom-index edge sets under that order. This supports mapping the bound mmCIF coordinates to the ideal-SDF heavy-atom identity for these exact hash-pinned inputs. It does not justify assuming atom order for arbitrary SDF/CIF pairs; the production path must validate the graph and persist the mapping. Hydrogens must be generated for the selected microstate, not copied from ideal coordinates after changing heavy-atom coordinates.
