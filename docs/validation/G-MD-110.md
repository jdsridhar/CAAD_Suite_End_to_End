# G-MD-110 — Ewald potential-modifier audit

**Finding:** The G-MD-79 independent pair-sum code subtracted the Ewald cutoff shift for included pairs, but its archived energy MDP/TPR explicitly says `coulomb-modifier = None`. This is a small input-model mismatch in the reference definition. Removing that included-pair term changes the mean five-frame reference residual by only 0.094 kJ/mol; the CPU/reference residual remains about 5.74 kJ/mol (reference minus GROMACS). A matched-seed GROMACS 2026.3 control produced a mean Coulomb-SR difference of +0.131 kJ/mol (range −1.344 to +1.344) for `Potential-shift` minus `None`. Two repeated reruns of each of the ten TPRs reproduced each value exactly (maximum repeat difference 0.000 kJ/mol). Thus the small observed modifier difference is stable for this setup; it does not explain the several-kJ/mol CPU/reference residual. A separately computed +39.249 kJ/mol excluded-pair charge-product constant is not a valid standalone correction and was not applied.

## Method

Used G-MD-79 GRO-rounded frames: replica 1 at 100/200/300/400 ps and replica 2 at 100 ps. Each frame/box was preprocessed from the same topology into paired TPRs with only the `coulomb-modifier` setting changed. Both used explicit `ld-seed=44101`. Each TPR was rerun twice using the same coordinates and box; all repeat energies matched exactly at reported precision. PME grid 60×81×48, ewald-rtol 9.9979e-5, Coulomb/vdW cutoffs 1.0 nm. CPU energy-only reruns used one MPI rank and four OpenMP threads. No dynamics were integrated.

The 27,365 topology exclusions have sum(qi*qj) = −2825.56148 e². Multiplying by the Ewald shift coefficient gives +39.24879 kJ/mol as an isolated algebraic value. That product is diagnostic only; it is not asserted to be a valid correction to GROMACS's complete direct/reciprocal exclusion expression.

The adjustment leaves the thread-count pattern essentially unchanged, but narrows G-MD-79's exact formula-matching claim.

## Matched Amber Sander comparison

Using the existing Sander verbose Ewald decompositions generated from these same five GRO-rounded frames, Amber direct+self+adjust minus GROMACS CPU-4 Coulomb-SR is **+15.964 kJ/mol** (range **+15.769 to +16.088 kJ/mol**, or +3.815 kcal/mol mean). This comparison is coordinate-matched and is a subtraction of diagnostic groups; it does not prove identical term definitions. G-MD-109's −2.484 kcal/mol GROMACS-minus-Amber short-range-group mean came from a separate 15-frame full-precision set. The two sample sets are not pooled; [G-MD-111](G-MD-111.md) crosswalks five common timestamps and shows that the CPU-vs-GPU short-range backend difference accounts for most of their mean gap. A same-coordinate full-precision CPU/GPU rerun remains the next validation control. The Amber-vs-pair-reference source JSON SHA-256 is recorded below.\n\n## Limits

The five frames are correlated and from one system; GRO coordinates are rounded. This supports only the measured modifier difference for these fixed coordinates, GROMACS build, and CPU settings; it does not establish a general energy convention or explain cross-engine residuals. No tolerance, compatibility qualification, or trajectory claim follows. Continue by reconciling the five-frame GRO-rounded and 15-frame full-precision Amber/GROMACS grouped residuals, then expand controlled accumulation/backend comparisons to chemically distinct systems.
