# G-MD-117 — 4W52 readiness minimizer continuations

**Disposition:** Reject 4W52/benzene for the current independent Amber/GROMACS readiness gate. Two further minimizer continuations from the retained XMIN checkpoint terminated on optimizer failures, and independently evaluated endpoint RMS gradients remain above the unchanged 0.0001 kcal mol-1 A-1 criterion. This is a decision about this prepared model and validation role; it does not imply the crystallographic system is generally unusable. No production or sampling MD was performed.

## Methods and results

The starting restart was the saved 1,000-cycle XMIN checkpoint from G-MD-114 (SHA-256 0fe67e815cb16b59837f3e41c785031dfe3318911de4fccd83be335c0a75db67). A zero-cycle Sander evaluation reproduced its RMS gradient 0.061101 and GMAX 5.3884.

| Continuation | Settings and starting point | Terminal event | Independent endpoint evaluation |
|---|---|---|---|
| XMIN/LBFGS recheck | Same topology, PME/cutoff, restraints and 5,000-cycle input as G-MD-114; starts at saved 1,000-cycle checkpoint | Amber emitted ERROR in load_lbfgs(): YS=0 at cycle 1,523 | RMS 0.0057767; GMAX 0.72278 at CG ASP9 atom 174; EAMBER −87645.3486 kcal/mol |
| Existing SD/CG recipe | Retained minimization4 input; 1,000 steepest-descent cycles followed by conjugate-gradient, 5,000-cycle cap; starts at independently verified XMIN endpoint | Repeated line-minimization failures; stopped at cycle 1,888 | RMS 0.0035926; GMAX 0.15216 at H2 atom 19358; EAMBER −87649.3677 kcal/mol |

The independent endpoint checks used the same zero-cycle Sander single-point input, topology, reference coordinates, PME/cutoff and positional restraints. The reported RMS is compared with the retained drms=1e-4 criterion. The best endpoint is still about 35.9 times above that value. A lower energy and lower gradient than the earlier 5,000-cycle endpoint do not constitute a converged minimization.

This follows the G-MD-116 correction: Sander's EAMBER excludes positional-restraint energy, while the minimizer's total objective and force include it. The readiness decision uses the independently reported total-gradient RMS, not EAMBER alone.

## Decision and next step

Do not run MD from these endpoints and do not enable the Amber/GROMACS compatibility profile. Retain the original atom mapping, ligand parameters, force field, restraint weight and convergence criterion; no parameter or threshold was altered to force a pass. Select a different chemically distinct crystallographic protein–ligand system with a defensible preparation path, then repeat the independent Amber readiness gate before considering any dynamics.

The prior 4W52 candidate triage (G-MD-113) is superseded on this point. The energy/force and parameter diagnostics remain useful evidence for the platform, but 4W52 no longer serves as the next independent readiness system.
