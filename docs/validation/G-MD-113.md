# G-MD-113 — Independent Amber protein–ligand system readiness triage

**Decision:** No available candidate is currently authorized by its recorded validation evidence for new Amber/GROMACS production dynamics. The most suitable distinct protein–ligand candidate already built through the platform is 4W52/T4 lysozyme L99A–benzene, but its readiness gate remains failed. Preserve that gate; do not infer MD readiness from successful topology generation or an OpenMM minimizer stopping criterion.

## Candidate evidence

| PPARG/ergosterol peroxide | Existing 100 ns CHARMM-GUI/CGenFF simulation, G-WORKFLOW-2 and G-LIGAND-IDENTITY-1 | Not a valid Amber cross-engine candidate: the source ligand parameterization has penalty 190.7 and an unsupported peroxide group. Reparameterizing it with GAFF would create a different, as-yet-unvalidated model. |

## Next gate

Retain 4W52/benzene as a **candidate for further readiness work**, not as a qualified validation system. Before any dynamics, resolve and record a defensible minimization endpoint for the selected Amber and GROMACS representations, inspect all bonded/nonbonded geometry and ligand parameter assignments, and reconcile the fixed-frame energy/force terms across independently selected configurations. If the candidate cannot pass those checks without arbitrary thresholds or unvalidated parameter changes, reject it and select a new structurally supported complex.

Only after the preparation gate passes should a bounded equilibration/stability run be considered. Production sampling and compatibility qualification require additional independently equilibrated configurations and matched energy/force comparisons. No tolerance or Amber/GROMACS compatibility profile is proposed by this triage.
