# G-MD-112 — Full-precision CPU/GPU short-range backend control

**Finding.** On five full-precision snapshots shared by CPU-PP and GPU-PP energy-only reruns, CPU Coulomb-SR minus the Amber `direct+self+adjust` group averaged **−3.84786 kcal/mol**, GPU-PP averaged **−2.50046 kcal/mol**, and CPU-PP minus GPU-PP averaged **−1.34739 kcal/mol** (range −1.41163 to −1.27719). This agrees closely with G-MD-111's same-coordinate, GRO-rounded backend difference of −1.3459 kcal/mol. CPU Coulomb-SR repeated exactly at extracted XVG precision on all six frames in each replica. GPU repeats were close but not identical: across 12 replica/frame observations, Coulomb-SR repeat-minus-first ranged −0.28125 to +0.25 kJ/mol (mean absolute change 0.10677 kJ/mol). The GPU repeat variability is smaller than the observed mean backend difference in this sample, but its cause is unproven.

## Method

GROMACS 2026.3-conda_forge `mdrun -rerun` used the same `energy.tpr` and same full-precision `energy-whole-rerun.trr` per replica for CPU-PP and GPU-PP. Settings: one MPI rank, four OpenMP threads, PME on CPU; CPU used `-nb cpu`, GPU used `-nb gpu -gpu_id 0`. Each replica/backend was run twice. Six frames (0–500 ps at 100 ps intervals) were extracted from each EDR for Coulomb-14, Coulomb-SR, and reciprocal terms. No dynamics were advanced. The five Amber comparisons are replica 1 at 100/200/300/400 ps and replica 2 at 100 ps, against Sander's diagnostic `direct+self+adjust` grouping from G-MD-109; term equivalence is not asserted.

On the five comparison frames, GPU repeat-minus-first averaged −0.00149 kcal/mol (range −0.06722 to +0.05975). Two runs per setting are not a statistical characterization of GPU variability.

## Interpretation and limits

Holding both the coordinates and TPR fixed removes GRO coordinate/box precision as a confound in the CPU/GPU comparison. The measured −1.34739 kcal/mol backend shift closely reproduces G-MD-111, supporting the conclusion that backend selection accounts for most of the earlier sample-mean difference. This remains diagnostic evidence from five correlated frames of one pose-derived system. It is not a general backend error bound, does not explain the residual several-kcal/mol GROMACS/Amber difference, and does not qualify Amber/GROMACS compatibility, set a tolerance, or establish trajectory equivalence. No production MD was run; the compatibility profile remains disabled.
