# ADR-0032: Normalize MD stage results and validate engine output at the adapter boundary

- **Status:** Accepted
- **Date:** 2026-09-25
- **Context:** GROMACS and OpenMM implement the engine-neutral planning port, but a scheduled stage needs a durable normalized result and engine-specific output checks. GROMACS can exit successfully while `grompp` reports a scientifically relevant warning. The existing warning classifier must not be bypassed by a generic runner.
- **Decision:** Add `MDStageResult` (`md_stage_result/1.0`) as the output for one successfully completed protocol stage or production segment. It links the MD system and stage input, records stage/segment identity, engine and adapter software references, effective parameters, runtime, and hash-linked artifacts. Extend `MDExecutionEngine` with `validate_execution_step(context, step_index, stdout, stderr)`. Each engine owns interpretation of its own outputs; GROMACS applies the existing blocking warning classifier to the fresh-stage `grompp` command, while OpenMM currently adds no separate warning rule. The application runner will remain responsible for argv execution, storage, attempt provenance, and constructing the normalized result.
- **Consequences:** Raw logs and engine outputs remain artifacts; task/attempt state indicates execution status, while `MDStageResult` represents successful normalized output. A sequence of stage results can later be assembled into `MDSimulation` and `Trajectory` records without confusing one segment with an entire simulation.
- **Validation:** Unit tests cover hash-linked results, adapter-selected materialization, and GROMACS warning routing. A 50-step CPU GROMACS production run passes through the installed stage plugin and LocalWorkflowRuntime with a successful normalized result, TaskAttempt, two argv/log records, and a captured Conda lock. Full repository gate: 514 passed, 25 skipped; strict mypy (164 files), import-linter, schema freshness, and Ruff pass. This short run verifies execution plumbing, not long-timescale stability or force-field accuracy.
