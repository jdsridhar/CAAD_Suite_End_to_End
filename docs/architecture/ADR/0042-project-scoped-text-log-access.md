# ADR-0042: Project-scoped bounded text-log access

## Status

Accepted

## Context

Run provenance stores references to raw stdout/stderr artifacts, but the browser
could not inspect their contents. Returning arbitrary artifact bytes or accepting
filesystem paths from the UI would weaken storage isolation.

## Decision

Expose a project-scoped text endpoint that returns at most one megabyte from the
tail of a text/plain artifact. The server checks that the artifact is explicitly
linked to the project or was used/generated by a task attempt belonging to one
of that project's workflow runs. The content-addressed store resolves bytes by
verified hash; clients never supply a path.

## Consequences

- The browser can inspect provenance-linked logs without exposing storage paths.
- Binary/structured artifacts are rejected by this endpoint and remain available
  through specialized viewers or export APIs.
- The current UI displays log tails, not a durable live log stream.
